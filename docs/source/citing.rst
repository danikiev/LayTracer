.. _citing:

======
Citing
======

If you use LayTracer in your research, please cite it as follows:

| **Anikiev, D. (2026).** *LayTracer: Fast two-point seismic ray tracing in layered media.* Zenodo. 
| https://doi.org/10.5281/zenodo.18850919

.. admonition:: In BibTeX format for collective DOI
   :class: tip
   :collapsible: closed

   .. code-block:: bibtex

      @software{Anikiev2026LayTracer,
         author    = {Anikiev, Denis},
         title     = {{LayTracer}: {F}ast two-point seismic ray tracing in layered media},
         year      = {2026},
         publisher = {Zenodo},
         doi       = {10.5281/zenodo.18850919},
         url       = {https://github.com/danikiev/LayTracer}
      }

The DOI above represents all versions, and will always resolve to the latest one.
To cite a particular version of LayTracer, please use the following format, e.g. for version 0.4.0:

| **Anikiev, D. (2026).** *LayTracer: Fast two-point seismic ray tracing in layered media (0.4.0).* Zenodo.
| https://doi.org/10.5281/zenodo.19983599

In BibTeX format:

.. admonition:: In BibTeX format for specific version
   :class: tip
   :collapsible: closed

   .. code-block:: bibtex

      @software{Anikiev2026LayTracerVersion,
         author       = {Anikiev, Denis},
         title        = {{LayTracer}: {F}ast two-point seismic ray tracing in layered media},
         year         = {2026},
         publisher    = {Zenodo},
         version      = {0.4.0},
         license      = {MIT},
         doi          = {10.5281/zenodo.19983599},
         url          = {https://github.com/danikiev/LayTracer}
      }
