Dependencies
------------

LayTracer relies on the following Python libraries:

* `NumPy`_: A fundamental package for scientific computing in Python.
* `SciPy`_: A library for mathematics, science, and engineering in Python.
* `Matplotlib`_: A plotting library for Python.
* `Plotly`_: An interactive graphing library for Python.
* `Joblib`_: A set of tools to provide lightweight pipelining in Python.

.. _NumPy: https://numpy.org/
.. _SciPy: https://scipy.org/
.. _Matplotlib: https://matplotlib.org/
.. _Plotly: https://plotly.com/
.. _Joblib: https://joblib.readthedocs.io/

LayTracer builds upon the open-source ecosystem, and the author gratefully acknowledges these tools.
